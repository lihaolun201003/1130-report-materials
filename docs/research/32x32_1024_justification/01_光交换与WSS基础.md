# 光交换与 WSS 基础

## 从外部交换端口数到内部物理链路数

| 名称 | 对象与动作 | 32 或 1024 的计数含义 |
|---|---|---|
| OCS（光电路交换） | 在光域建立并保持可重配的电路。数据中心 MEMS OCS 可用镜面改变光束方向 | 32×32 为 32 个外部入端口、32 个外部出端口。单播一对一状态的峰值是 32 条电路，可能配对 1024 个 |
| OXC（光交叉连接） | 把入端口来的光信号引到目标出端口。实现可按整根光纤交换，也可按波长交换 | 要先声明交换粒度。内部资源随两级直连、交叉阵列、Clos 或混合架构改变 |
| ROADM（可重构光分插复用） | 在光传送节点对各方向线路实施波长转发和本地上下路 | degree 指节点线路方向或设备支持的线路维度。平行纤对、备用口及本地 add/drop 另记 |
| WSS（波长选择开关） | 把同一输入纤的不同频谱槽独立分给不同分支，或从多个支路选出互不冲突的频谱合入公共口 | 1×32 指 1 个公共端口和 32 个分支光端口。波长数由频谱规划另计 |
| 无源 Shuffle | 对已有物理通道实行固定重排。普通一对一版没有控制器和分光 | 32 组各 32 根时，有 1024 条固定连线和 2048 个光学端点 |
| MZI 开关单元 | 利用两臂相位差改变出端口，每个单元是可调有源器件 | 1024 个 MZI 只是元件库存。单元数量取决于交换拓扑，物理端点及独立中间光路另算 |
| 电 I/O 与 WDM | 电 I/O 统计并行数据引脚。WDM 统计同一空间介质上的光载波 | 电引脚、波长、独立光纤和独立玻璃波导分别计数 |

[Cheng 等 §II][S01] · [Google Apollo §3][S08] · [Gao 等 Fig. 1–3][S06] · [Intel OCI][S21]

## Cheng 等人的标准 route-and-select OXC

原文 p.7319 Fig. 1 图注和 §II.B 的线路描述给出两级 WSS 及其固定连接。输入端是 N 个公共端口对应 N 只 1×N WSS。输出端是 N 只 N×1 WSS，其公共端口形成 N 个系统出口。分别把左侧 WSS 的分支作为 Shuffle 输入组、右侧 WSS 的分支作为 Shuffle 输出组。每组间有一根线，线路标签中的组号和支路号对调。p.7320 Table I 给出连接矩阵，P1 要求每个输入组、输出组对恰好一条线，P2 要求双下标反转。Fig. 2 的两个 1×2 WSS 状态图说明同一根输入纤内不同波长可以被分别送到两个输出。§II.B 定义句存在索引文字歧义，采用其 P1/P2、后续 pq 到 qp 的明文叙述和 Table I 作为连接规则。[Cheng 等，原始论文][S01] · [作者机构全文入口][ChengPDF]

令输入组 i 表示入口 WSS，输出组 j 表示出口 WSS。一次光路经过下列元件。

```text
系统输入 i → 1×N WSS i 的支路 j
           → 固定光路 (i,j) → (j,i)
           → N×1 WSS j 的支路 i → 系统输出 j
```

| 对象 | Q(N) 数量 | Q(32) 数量 |
|---|---:|---:|
| 系统线路入、出端点 | 各 N | 各 32 |
| WSS 功能单元 | 2N | 64 |
| 左、右 WSS 连接至重排层的分支端点 | 各 N² | 各 1024 |
| 固定中间光纤 | N² | 1024 |
| 中间层全部端点 | 2N² | 2048 |
| WSS 各单元物理端点合计，含公共口 | 2N(N+1) | 2112 |

最后一行是 WSS 光端点总数，前几行是同一批端点在不同接口处的计数，不能相加。单向模型中若不装对角连接，则固定纤数为 N(N−1)。同一编号若只是两套独立设备的逻辑标签，i=j 仍是合法组对。双向传输如果采用双纤且需两套独立方向的净表，按两套净表分别计数，不能只因设备标注双向就自动把 Fig. 1 翻倍。

## 32×32 与 64×64 原型的数量核对

| 实物 | 外部端口与可选组合 | 实际中间结构及并发边界 |
|---|---|---|
| Han 等的硅光 MEMS crossbar | 32 入、32 出、1024 组可选配对 | Fig. 1 中输入沿横排波导进入，输出沿纵列波导离开，交点的梳驱动调节耦合间隙。横纵导路共享，单播最多同时 32 路。[Han 等，§2 Fig. 1、§3][S05] |
| Gao 等的片上 switch-and-select | 32 入、32 出，32 个入口树与 32 个出口树 | §2 和 Fig. 1 的树端口对应 32×32 个专用中间配对，是固定转置的近邻架构。导光材料为片上 Si/Si₃N₄，路径可能包含多段及层间耦合。实物有 1984 个热光 MZI、2048 个层间耦合器和 246,016 个交叉。最多同时一对一连 32 路。[Gao 等，Fig. 1、Fig. 4][S06] |
| Tanizawa 等的 32×32 PILOSS | 32 入、32 出、1024 组可选配对 | OFC 原始摘要报告芯片集成 1024 个热光 MZI 。单播端口并发上限 32；MZI 是开关单元库存。[Tanizawa 等，OFC 摘要][S29] |
| Hu 等的 64×64 Beneš | 64 入、64 出、4096 组可选配对 | 采用 352 个多级 2×2 单元，连线与开关级可被不同配置利用。4096 路谱的测量覆盖逐配对；单播端口并发上限 64。[Hu 等，64×64 Results][S07] |

## 并发、无阻塞与部署条件

- OCS 单播端口矩阵每个输入、输出同时各占用一次。理想 N×N 有 N² 种可选端口对，最大并发 N。Apollo 的 Palomar 实例有 136×136 双射光路映射，由两组 MEMS 光束转向实现。136²=18,496 是可选配对，理论并发上限 136。Jupiter 系统论文给出生产业务网络中的 OCS 层，二者属于同一部署体系。[Apollo §3][S08] · [Jupiter §2–3][S09]
- WSS 架构对单一频谱槽同样受每个入、出公共口最多占一次的限制，32×32 单槽最多 32 路。若每口有 K 个等宽可用槽，在各槽独立且无保护保留、滤波和频谱连续性限制的上界下，可有 32K 条单槽电路。全部 1024 根固定纤可同时承载信号的一个充分构造，是至少 32 个独立槽且使用 k=(j−i) mod 32 分配输入、输出组对，使相同槽在每一侧均为匹配。实际并发依赖 WSS、跨节点频谱、通道宽度、光功率和争用约束。[Cheng §II.C][S01] · 本文推导。
- 直接接通每对 WSS 的益处是频谱合规时不用与其他组对共享中间支路。路由节点要跨不同线路方向转发、恢复或重新规划波长，因而需要选择余量。对于只转发已知局部流量的节点，稀疏固定背板、Clos、集成 M×N WSS 或 WSS–OCS 混合方案有不同资源曲线。Cheng §III 的三阶段模块化先分解 WSS，再分块 Shuffle，再组合子 OXC。§IV 使用 1×9、9×1 WSS 模拟/测试路径级传输，文中的比较针对给定架构和实验条件。[Cheng §III–V][S01] · [Hong 等混合架构][S30]
