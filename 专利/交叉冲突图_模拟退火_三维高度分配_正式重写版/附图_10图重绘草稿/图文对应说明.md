## 图 10 的几何与统计口径

| 指标 | E1 确定性分组 | E3 模拟退火分组 |
| --- | ---: | ---: |
| L7（−0.075 mm）平面光波导线路数 | 64 | 62 |
| L7 实际同高交叉事件数 | 1102 | 460 |
| 全部高度的同组端口弦冲突边数 | 5835 | 2273 |
| 全部高度的实际同高交叉事件数 | 6803 | 3275 |
| 布通线路数 | 1024 | 1024 |

L7 是这对方案实际交叉事件数差值最大的高度，且两组均有超过 60 条线路。两幅图都按 X、Y 各 0–150 mm 的范围，以等比例绘制 z = −0.075 mm 上的所有平面路径。矢量线段和圆弧来自 `routes_l3d.json`，圆弧以小角度 Bézier 段表示。标记为 `crossing_stats.json` 的 `crossing_events` 中同一高度的 (x,y)，每个标记对应一个事件。核验脚本逐一验证标记与参与的两条中心线相符，最大距离小于 0.000001 mm。两组的平面段均按实际 z 筛选。

同组端口弦冲突边数由 656 条可动线路的真实端口投影与目标高度独立复算。以说明书 [0023] 的 10⁻¹² 阈值处理二维有向叉积，枚举每个无序线路对，仅对严格相交且同组的弦对计数一次。两方案均采用家族独占高度，实际同一目标高度等价于同一家族同组。实际同高交叉事件按三维输出中的同高平面几何统计，同一线路对可贡献多个事件。E1 的分配顺序为 `port`，E3 为 `route_id`。本图的观测差值是两套实验方案的整体差异。

## 重新生成附图

`src/绘图数据.json` 保存绘图所需的高度、端口弦和 L7 原始几何摘录，可直接用于重画。SVG 的文字保留为可编辑文本，图形保留为矢量对象。默认字体为 Windows 微软雅黑，换机编辑时可安装同一字体或用 `--font` 指定有中文字形的 TrueType 字体后重新导出。PDF 已嵌入所用字形。PNG 由交付 PDF 渲染。

在本目录运行以下命令。第一条可结合原始实验目录重新核验并提取，第二条生成全部图及总览。绘图依赖 Python 3.10+、matplotlib、numpy、Pillow 和 PyMuPDF。

```powershell
python src/check_data.py
python src/draw_figures.py
```

`check_data.py` 接受 `--experiment` 指定含完整 E1/E3 路径的实验目录，也可用 `--report-repo` 指定 GitHub 固定提交的本地检出目录，补做逐文件哈希对照。绘图脚本检查 10 份 SVG 中的文本和矢量结构，以及 10 页 A4 合并 PDF 的图号、页尺寸和嵌入图形。
