## Data-quality caveats

* crossing counts: the authoritative crossing_stats.json totals (1283 events / 1221 pairs) are reproduced exactly by recomputing the real line/arc intersections of every flat part of every route (plots21.compute_crossings semantics); the per-event marker positions in the figures are those recomputed exact intersections.
* crossing_stats.json of this layout stores aggregate counts only (no per-event x/y list); the crossing markers drawn here are recomputed from the real line/arc primitives.
* figures 06/07 read the six 20H stage directories at generation time (no timestamps are embedded in any figure): if a later stage is still running (for example 06 native-3D phase 2), rerun this script after it finishes so the curve / bar comparison reflects the final stage values.
