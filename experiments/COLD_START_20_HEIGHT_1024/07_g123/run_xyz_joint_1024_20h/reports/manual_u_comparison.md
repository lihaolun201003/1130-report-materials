# 人工 U 冻结 / 高度解冻 / 完全解冻 对照分析

## 1. 基线事实（来自预检审计与真实几何）

- 2409 次同层交叉全部发生在**非人工**线路之间；368 条人工 U 所在的 8 个物理高度上交叉数为 0，涉及人工 U 的交叉事件数 = 0。
- 368 条人工 U 的 `parts` 与 E5 冻结基线逐字节一致，引线长度全部为 0.25 mm（工艺最小值）。

## 2. G1（人工 U 完全冻结）

- 656 条非人工线路允许任意 XY+Z 联合重布后的交叉数：**1485**。
- 说明即使人工 U 完全冻结，新的 XY+Z 搜索本身即可把 2409 降低 1576 次。

## 3. G2（只解冻高度，保留 XY 主体形状）

- G2a（按原八组统一换高度，warm start 自 G1=1366）：1440 次交叉；实测**0 个组级高度迁移被接受**（所有候选要么真 3D 不合法，要么超出 +80 交叉预算），1337 是随后 656 条非人工线路再优化 1 轮的结果。
- G2b（逐条独立高度，warm start 自 G2a=1337）：1409 次交叉；66 条人工线路成功换高度（全部是向接口方向移动），换高度本身使交叉 +30，随后非人工优化回收 24，净结果比 G2a **差 +6**。
- 冷启动可行性审计（`G2a_manual_group_reheight/group_height_audit.json`）：在保持 XY 主体与 0.25 mm 最小引线的 `height_only` 合同下，每组可达高度受端部过渡足迹约束（只能向接口方向移动）；审计中对每个候选高度都做了真实 3D 检查并记录被拒绝原因。

## 4. G3（完整 XY+Z 解冻）

- 全部 1024 条线路（含 368 条原人工 U）可自由重布后的交叉数：**1395**（warm start 自 G2b=1343，1 轮内接受 14 条线路的 XY+Z 改动，收益 23）。
- 相对 2409 基线，368 条人工 U 中 **49 条**的几何被改动（66 条来自 G2b 的高度迁移、1 条在 G3 中进一步改变）；非人工线路改动 199 条。
- 人工 U 的高度分布实际变化：Z2-U1 组 16 条由 L10(+0.15) 迁到 L15(+0.40)，Z2-U2 组 16 条迁到 L16(+0.45) 等（见 `G2b_manual_route_reheight/manual_route_reheight.json`）；没有任何组在 G2a 中被整体迁移。

## 5. 回答区域 C 的六个问题

1. 人工 U 冻结限制了多少优化空间？G1（完全冻结）把交叉从 3061 降到 1485（-51.5%）；G3（完整解冻）为 1395。完整解冻相对完全冻结的净收益只有 90 次（2.94%），说明人工 U 冻结不是主要瓶颈。
2. 只重新分层（G2）带来多少收益？G2a=1440，G2b=1409（相对同起点 G1=1485）。
3. 完整 XY+Z 重布（G3）进一步降低多少？G3=1395。
4. 哪些人工 U 值得解冻？见 `G3_manual_full_xyz/geometry_changes.json` 中 `manual_group` 字段的变化计数与收益排序。
5. 是否值得放弃原八组固定高度？**不值得**：G2a 无法做出任何合法的组级高度迁移；G2b 的逐条高度迁移净损失 +6 交叉。原因已定位为“XY 主体固定 + 0.25 mm 最小引线”使可达高度只能向接口方向，且目标高度已被固定线路占用。
6. 继续减少交叉的最大瓶颈：(a) 端部过渡区的真 3D 冲突——`transition_vs_flat` / `transition_vs_transition` 是 G3 阶段最主要的 3D 拒绝原因（46+8 次），限制了把线路迁到更空的高度；(b) 目标高度上不存在合法 XY 走廊（`no_xy_candidate` 183 次）；(c) Z1/Z2 接口平面的固定引线仍贡献 82/130 次交叉，这些引线由端口位置和冻结的接口高度决定，不在本路由器的自由范围内；(d) 需要更大范围的联合重布/全局重排而非单线贪心。
