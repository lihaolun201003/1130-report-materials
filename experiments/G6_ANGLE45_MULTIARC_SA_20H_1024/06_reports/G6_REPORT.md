## 1. 本轮改变了什么（不是“把贪心换成退火”）

1. **几何构造阶段**：修改冻结的 2D MultiArc 生成器 `layer2d`，在它已经算出的严格 D56 交叉记录上直接读取**真实局部切线角**，用“合法候选池 + 角度评分”替换“首个可行候选即提交”。MultiArc 语法、R15、D56、端口位姿、板界全部逐位不变；只改候选选择规则（`G6_ANGLE_AWARE`，默认关闭）。
2. **搜索阶段**：新的 G6 内核直接在**完整 1024 路真实 XYZ 几何**上做模拟退火，状态可同时改变（高度、MultiArc 主体、R15 过渡），能量只由 45° 规则构成，允许暂时接受违规增加以越过局部最优。

## 4. G6 退火内核

### 4.1 状态与邻域

状态 `S = {z_i, G_i, T_i}`（高度、MultiArc 主体几何、R15 升降过渡）都是可变的；每个邻域一次改变一组线路，并用 G5 的**原子批量评价器**（移除旧几何 → 插入新几何 → 整组检查 → 恢复/提交）判定。硬制造约束永远不允许违反：结构/R15/玻璃/严格 D56/真三维 0.05 mm 净空/自净距不通过则直接丢弃。

| 邻域 | 操作 | 说明 |
|---|---|---|
| **N1** 单线路 MultiArc 重生成 | 固定端口位姿与高度，重新枚举冻结的 layer2d MultiArc 候选语法（U / opposite / adjacent / 短 S / detour / 回环 / 楼梯） | 主力；候选数 300–700/线路 |
| **N2** 两线路联合 MultiArc 重规划 | 同一残余违规的两条线路同时重生成 | 原子 batch；可修“单条单独改非法、两条同时改合法” |
| **N3** 多线路联合重规划 | 违规连通分量内 2–6 条线路同时重生成 | 原子 batch |
| **N4** 多线路联合层分配 | 2–4 条线路同时换高度，R15 过渡精确重建后整组评价 | 直接回应 G5 “DSATUR 19 色只是抽象上界”的失败模式 |
| **N5** 过渡区联合重构 | 端口引出长度（0.25–16 mm）与升降过渡几何联合重建 | 任务书允许的“端口附近合法引出长度”自由度 |
| **N6** 跨层 + MultiArc 联合 | 高度 + 圆弧 + 过渡 + 整组三维检查 | 完整 G6 |

### 4.2 能量、接受准则与温度调度

`E(S) = M·N_bad(S) + λ·D_theta(S)`，`M = 1000`、`λ = 1`（度）。一次 45° 违规（M）压过任何角度不足变化（≤45λ），所以 N_bad 优先、λ 只做引导。接受概率 `P = min(1, exp(-ΔE/T))`，允许暂时接受 51→53 这类变差的移动；最优状态单独保存并周期性用独立全量审计校正增量账本。

温度：`T_k = T0·(T_end/T0)^(t/budget)`，`T0 = 700`、`T_end = 45`；停滞 240 s 触发再升温（×2.5），接受率窗口 <3.5% 升温、>72% 降温；多随机种子、每 300 s 检查点、可从检查点恢复；找到 N_bad = 0 立即保存并停止。

### 4.3 确定性收尾（last-mile polish）

退火在最后几次违规上会停住（接受率与邻域命中率同时下降）。G6 增加一个**确定性穷举修复**阶段：对每个残余事件，枚举两条线路的**全部**合法 MultiArc 主体（+换层/引出/直通抬升变体），快筛后把最有希望的单线路与双线路组合交给原子 batch 评价，只提交全局违规数严格下降的移动。这一阶段把 Warm Start SA 的部分解（N_bad = 4）推到 0。

## 7. 讨论与限制

1. **总交叉数增加是允许的代价**：3061 → 4578（+49.6%），任务书明确“不要求减少总交叉数量，允许合法的大角度交叉增加”。最大单线路交叉数从 99 增至 99，均为 ≥45° 合法交叉。
2. **最小交叉角 45.108500°**：所有交叉严格 ≥45°；45.0–46° 附近的边界事件同时被 Validator B 的解析边界自检覆盖。
3. **assignment 偏差**：Validator A 记录 134 条线路的 assignment 行与实际高度不同（换层导致），这是任务书允许的合法工程变化，A 的几何/合同判定仍为 PASS（G5 报告也记录了同类偏差）。
4. **零违规解的来源**：Warm Start SA（12 种子 × 8 cycle，317496 次移动提议）把 51 降到最好 4，确定性穷举修复再降到 0。不是靠放宽任何判据或修改检测口径。
5. **独立复核**：另有第二条独立产生的零违规解（seed 1001，`04_validation/alternate_zero_seed1001/`）同样双验收 PASS，routes SHA256 与主交付不同——说明 0 违规不是一个幸运样本。
6. **SA-only 零解与 Validator A**：消融 D/E 的零违规是退火直接得到的（45° 规则满足），但其几何含 1 个切触（tangent touch）+1 个同平面净距事件，被冻结 Validator A 拒绝。原因是搜索侧 G5 模型与冻结 D56 判定在“切触/交叉窗口”语义上有已知差异（G5 报告 §2 也讨论过两套 D56 实现）；**最终交付只承认 A+B 同时 PASS 的解**，即确定性修复后的主解。
7. **早期起点路径**：构造阶段角度感知带来 −14.6%% 违规，但同一退火在早期大状态（~1000 违规）上预算内未能清零；这验证了“必须从完整几何继续搜索”，而不是“只改构造阶段就够”。

## 9. 关键结论（对应任务书十问）

4. **原 51 次相关冲突解决了多少？** 51/51 事件在“同一线路对”和“同一空间区域”两种口径下全部消除，39/39 原空间簇清零。

6. **是否获得零违规解？** **是**（`03_best_feasible/`，SHA256 `39a02c9ec9a598d9`；另有一个独立零解，两个都双验收 PASS）。…
