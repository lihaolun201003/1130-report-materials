## 1. 两个实验不是同一个实验

| | 历史消融（继承几何表达能力消融） | 本次严格消融（严格共同起点搜索消融） |
|---|---|---|
| 目录 | `G4_MULTI_ARC_ABLATION_1024/` | `G4_MULTI_ARC_ABLATION_FINAL_1024/` |
| ON 起点 | G3 最优解（**1322**），含 197 条多圆弧线路 | 转换后状态（**3967**），多圆弧线路 0 |
| OFF 起点 | Stage-0 转换后（**3967**） | **同上，完全相同** |
| 是否含"把继承几何重表达"这一步 | 是（197 条线路，+2645） | **否**（共同起点已无多圆弧） |
| 预算口径 | 墙钟（ON 3119 s，OFF 1994 s，OFF 提前停） | **等候选评价计数**（24000 d56）+ 等墙钟（900 s）辅助 |
| 种子 | 1 个（20261104） | 3 个（20261104 / 20261116 / 20261130） |
| 能测量的效果 | A + B + C 混在一起 | **只测 B**（同一初始几何、同一预算） |

因此：

* 历史结果里的 `3484 − 1202 = 2282` **不能**读作"多圆弧让搜索更聪明"；
  其中 `2645` 是"把 197 条继承线路重新表达"的一次性几何代价（效果 **A**）。
* 本次结果里的 `ON vs OFF 差` 才是"允许 vs 禁止该几何自由度"的搜索能力差（效果 **B**）。

## 2. 效果分解（三件事必须分开）

```
效果 A  几何转换代价       = 1322 → 3967 的 +2645（197 条线路重表达）

                            = A + B + 预算/起点差异，不能单独归因
```

## 4. 原有结论有多强？

**可以支持的**：

1. 在**该框架、该起点、该候选语法**下，取消平面多段组合圆弧会迫使 197 条线路改用
   ≥4R 的绕行环路；这一步单独就带来 **+2645** 次交叉（本次已逐条独立重放验证）。
2. 这个代价几乎全部集中在亚 2R（|bx| < 30 mm）的横向错位：145 条贡献 +2646，
   52 条 ≥2R 的合计 −1（本次复算完全一致）。
3. 取消多圆弧后的最终解（3484）比 ON 最终解（1202）多 2282 次交叉，
   且**总长度同时增加 5.3%**——不是"用更长的线换更少的交叉"。

**不能支持的**：

1. **不能说"多圆弧让优化器更聪明"**：历史 OFF 臂从更差的 3967 出发，
   搜索收益（−483）反而大于 ON 臂（−120）；差异主体来自起点，不是搜索。
2. **不能把 2282 全部算作"多圆弧的价值"**：它混合了效果 A 与预算不等
   （OFF 少跑 36% 墙钟）。
3. **不能外推到"所有光滑曲线"**：结论只覆盖冻结 D56 候选语法。
4. **不能外推到"从零重新设计"**：若允许重选 fanout 落点使错位都 ≥2R，
   无多圆弧的系统本可以好得多（见旧报告 §6.5）。
5. **不能外推到光学损耗**：本实验只测几何与交叉，不测插入损耗。

## 5. 本次实验加强了什么、仍然缺什么

**加强**：

* 起点、预算、代码、约束、Validator 全部对齐后，"多圆弧 ON 明显优于 OFF"依然成立
  （见 §3.2 与 `tables/summary_c1.md`），因此效果 B 不再被效果 A 污染；
* 机制链条闭合：2R 阈值在**参数化语法枚举**中被复现（`tables/param_2r*.csv`：
  d ≤ 2R 时 OFF 只能用 4 弧绕行；travel < 4R 时 OFF **无解**），
  在**真实线路**中被复现（142/197 条被转换线路在 ON 中重新获得多圆弧几何，
  并贡献了绝大部分交叉下降，见 `tables/repair_*.json`）；
* 3 个种子的方向一致性（见 `tables/summary_c1.md`）。

**仍然缺**：

* 只有 3 个种子 ⇒ 探索性统计，不做显著性检验；
* 只有一个硬件/一天内运行，未能排除机器漂移（等墙钟臂受此影响最大）；
* 只研究一个起点状态（3967）；其他起点（例如直接从 G3 出发的 ON 臂）不在本次范围内；
* 没有做"允许重新分配高度/落点"的联合实验，因此不能回答"如果一开始就不需要亚 2R 错位"。

**为什么本次没有到 1185**（完整分解见 `report.md` §7.4）：

1185 是**从 1322 出发**的历史解，本次起点是 3967——同一个网络在"禁用多圆弧"之后的状态。
逐条分解显示 2203 − 1322 = +881 次事件来自两处：
① 197 条被转换线路的残余 +515（142 条已重新用上多圆弧，但只有 13 条与 G3 逐图元相同，
   残余的 70% 集中在 **99 条被 Stage-0 顺带改了高度**的线路上）；
② 其余线路的残余 +366（其中 567 条根本没被动过，是被"修复后的 197 条"的新交叉关系拖高的）。
搜索只接受严格下降的移动，因此它到达的是**另一个局部最优**，而不是"G3 还没跑完"。
预算也确实还没跑满（上限处仍在下降，约 −22 次/1000 d56），但按该斜率外推还需约 3 倍预算，
且这是次线性收益——**不能**据此声称"多给预算就能到 1185"。

## 6. 结论口径（写论文时请照抄这一段）

> 在冻结的 D56 平面候选语法、1024 通道、21 物理高度、R15、D56 与三维净空全部不变的条件下，
> **把继承的多圆弧几何用无多圆弧语法重新表达**本身即造成 +2645 次同层交叉（起点 1322 → 3967）；
> 在此**共同起点**上，以**相同候选评价预算**继续搜索，允许平面多段组合圆弧的一组
> 稳定地收敛到显著更低的交叉数（见主结果表），其收益主要来自对亚 2R 横向错位的紧凑表达，
> 代价是略长的路径与更多的圆弧；该结论限定在该候选语法与该起点之内，
> 不构成对任意光滑曲线、也不构成对光学插入损耗的结论。
