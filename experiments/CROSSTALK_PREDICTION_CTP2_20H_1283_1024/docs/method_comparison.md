# CTP-2.0 方法对照与适用边界

本文件回答：**每个物理量用什么方法算、为什么用它、它在什么范围内可信、我们用什么证据确定这个范围。**

所有"可信范围"都来自本仓库内的实测（见各节引用文件），不是引自教科书。

## 3. 为什么这样分区：实测依据

### 3.1 BPM 的上限为什么是 30°

| 依据 | 数值 |
|---|---|
| 2-D vs 3-D BPM 在 θ≤10° 的最大差 | **0.93 dB**（7 个对照点） |
| 独立 4 阶 2-D FDTD vs 我们的 2-D BPM | **0.13 dB @10°、2.25 dB @20°、2.44 dB @30°** |
| 独立 FDTD 的端口地板 | −71…−78 dB（远低于被测量的 −50…−60 dB） |
| BPM 在 45° 的非物理迹象 | T_through=0.37（应为 ≈0.99） |
| 文献（Chu & Chaudhuri 1989）验证过的 BPM 范围 | θ<4°，小 Δn，不含反射 |

→ 本文把 BPM 用在 θ≤**30°**（由独立全波实测放宽，不是理论声称），30–45° 只作为争议上界，>45° 停用。

### 3.2 Born 为什么**不能**作为 10–30° 的主方法

一阶 Born 的截断误差通常按 O(|a|) 估计：

| θ | |a| | 预期相对误差 |
|---:|---:|---:|
| 5° | 0.738 | 74 %（不可用） |
| 7.5° | 0.198 | 20 % |
| 10° | 0.0297 | 3 % |
| 20° | 9.7e−4 | 0.1 % |
| 90° | 2.87e−7 | 3e−5 % |

但实测推翻了这一估计：**20° 时 Born 给 −60.3 dB，独立 FDTD 给 −50.65 dB（差 10 dB）；30° 时 Born −78.9 dB、FDTD −59.76 dB（差 19 dB）**。原因是本问题的**折射率扰动并不弱**：`k₀²Δn²/(2β)·A ≈ 0.0311×81 ≈ 2.5`，Born 级数的二阶项虽然最终振幅很小，却与一阶项同量级。10° 时 Born 与 BPM 仅差 0.3 dB 是**巧合**（该点 |a|=0.03，一阶项本身很大）。
→ **Born 仅用于 |a|<10⁻³ 且无其他方法可用的 θ>45°**，并在该处标注为渐近估计、上界 −60 dB。Born 的 2-D 数值积分本身已做 n_q/n_s/q 范围收敛检验（变化 <0.1 dB），误差不在积分。

### 3.3 为什么 FDFD 在倾斜交叉上不可靠

5 点二阶格式的色散：离散波数 `k_disc = (2/h)·asin(√λ·h/2)` 满足 `(4/h²)sin²(k_disc h/2)=λ`。

| h [µm] | βh | 离散 β 相对连续 β 的偏差 |
|---:|---:|---:|
| 0.20 | 1.44 | **+11.7 %** |
| 0.15 | 1.08 | **+5.67 %** |
| 0.10 | 0.72 | **+2.31 %** |

交叉的两个臂相对网格取向不同（差 θ），各向异性的色散误差**不抵消**；在 9–30 µm 的干涉长度上，累积相位误差 0.3–3 rad。这就是为什么 CTP-1.0 的 0.15 µm 网格即使入射模正确也算不对倾斜交叉，也是本文 FDFD 只在 ≥45°（相互作用区最短）使用的理由。

### 3.4 交叉方向判据（CTP-1.0 缺失）

交叉把功率送入"与入射传播方向成锐角"的那一臂：

* 两方向切向量点积 > 0 → 锐角臂 = 对方**前向**臂 → 功率到达对方**目标端口**，计入 `T[j,i]`；
* 点积 < 0 → 锐角臂 = 对方**后向**臂 → 功率从对方**源端口**离开，不计入端口传输矩阵（只贡献插损）。

实测：1283 次交叉中 **856 次**属前者、**427 次**属后者。CTP-1.0 无条件双向累加。
（验证：`scripts/run_board_ctp2.py::build_events` 的 `tangent_dot` 列源自解析切向；2-D BPM 的几何 `arm1: x=+z tan(θ/2)`、`arm2: x=−z tan(θ/2)` 两条前向臂夹角恰为 θ，与判据自洽。）

## 5. 没有做到 / 明确做不到的事

1. 10–30° 的绝对串扰无法收敛到唯一数字（Born vs BPM 地板差 1–17 dB）。已给上下界。
2. 未做全矢量（偏振）与制造扰动。大角度串扰的实测值（−30…−50 dB）由这些因素主导，本文给的是理想结构下界。
3. 没有对同参数（Δn=0.0065、9 µm、few-mode 玻璃）的文献实测做直接对标——文献中不存在。
4. 论文 A（Adikan 2006）与论文 B（Hammer 2017 HCMT）全文未获取；HCMT 未按原文实现。
5. 未做相干多源叠加（1024 个独立光源，功率非相干叠加）。
