# CTP-1.0 → CTP-2.0：必须改什么（决策导向）

依据：`audit/ctp1_code_audit.md`（源码级缺陷）+ `audit/ctp1_anomaly_reproduction.md`（实测证据）。每条给出**可验收的技术要求**与**本审计的实测依据**。

---

## P0（不修则任何全板串扰数字都不可用）

**P0-1 端口功率必须由正确的入射模驱动，并由 Poynting 通量定义**
* 入射场必须是输入波导**真实背景结构**的离散导模（取穿过芯的列、用 n²，不得再平方），其传播常数用离散色散关系 `β=acos(1−Λh²/2)/h`；端口功率用 `P=(1/2ωμ₀)Im∫ψ*∂ψ/∂n dℓ`，并**显式给出入射功率归一**。
* 实测依据：legacy 的 `crossing.py:197` 使 ψ_inc 与真导模重叠²=9.1e-10；修正后同设置 T_cross 从 1e-8 变到 1e-5…1e-3。
* 验收：无交叉对照下 `|ψ_s|` 恒为 0（恒零可接受）；有交叉时 `|1−T_through−R−T_cross−Radiation| < 1e-3`，且 T_through<1 对所有角度成立。

**P0-2 端口必须位于"波导已分离"的区域，且四臂都要算**
* 端口平面处两波导间距必须 ≥ 约 3 个倏逝衰减长度，即 `d_sep ≥ 3/γ ≈ 5.4 µm`（更稳妥 ≥20 µm）；用**非对称域**把端口放在真正自由的位置，而不是靠 `d_port/sinθ` 且端口仍在芯区重叠区。
* 两条交叉臂（±u）都要分析；相位匹配的 +u 臂功率为主，−u 臂用于校验（实测 5° 时 −u 臂仅 3.9e-8 vs +u 1.08e-5，可作一致性检查）。
* 实测依据：legacy 在 5° 的 u_port=114.7 µm 处两波导仍处 |u|<103 µm 的芯区重叠区；A 节 5° 修正值在端口 d=10 与 d=20 µm 两套域之间仍需对比（见 `a3_domain_test_5deg.json`）。
* 验收：把 d_sep 从 20 µm 增到 40/60 µm 时，T_cross 变化 <10%（否则说明端口仍受近场污染）。

**P0-3 交叉求解器必须有网格收敛与能量守恒作为硬门禁**
* 每个角度至少 3 个网格（如 0.20/0.15/0.12/0.10 µm）报告 T_cross/T_through；网格色散对 β 的系统偏差必须记录（实测 +11.7%/+5.67%/+2.31%）。
* **小角度（θ≤15°）必须使用更细网格 + 域无关性检查**：本审计实测 5° 时域从 ±126 µm 增到 ±180 µm 使 T_through 从 0.958 变到 0.675（30%），10° 时 h=0.20 vs 0.15 的 T_through 为 0.800 vs 0.957（16%）——说明这些结果尚未收敛。CTP-2.0 的小角度交叉必须在 h≤0.10 µm、域 ≥±230 µm（~1–2×10⁶ 未知量）下做收敛表，并报告 T_through/T_cross 的网格--域不确定度带；否则只能给"≤/≥"界。
* 90°（物理 T_cross≲1e-11）作为**数值底标定角**：修正实现的实测底为 1.1e-9…1.2e-8（PML 强度/厚度影响小、网格主导）。所有角度的 T_cross 低于 1e-8 一律报 "≤1e-8"，不得当作预测值。
* 验收：同一角度 3 个网格的 T_cross 极差 < 2×；90° 底 ≤1e-8；T_through 跨配置变化 <1e-6。

**P0-4 全板矩阵必须让每个交点的 p 依赖角度/模式/几何，且能量守恒显式校验**
* `p_cross(θ, mode, geometry)` 必须来自局部求解器并**同时用于注入与直通扣除**；不得再用常数 p_floor。
* 删除"T_upper = T_nominal"式的伪上界；若要给不确定度带，应基于网格/模态/κ 的区间传播。
* 列和 ≤1 必须是**校验结果**而不是声明；实测常数 p 且 α=0 时列和 =1.00014（p=1e-3）、1.0137（p=1e-2），"by construction" 不成立。
* 验收：矩阵列和 ≤1（含二阶项）；用角度相关 p 后，最坏对/最坏泄漏随 p(θ) 的分布可追溯；二阶项相对一阶 <1e-9。

**P0-5 超模 κ 必须改用对称矩阵求解，或直接用重叠积分**
* 若保留半域超模法：Neumann ghost node 必须写成**对称**形式（对角 −2/h²…（2-D 中为 −4/h²）且 `A[r,r+1]=A[r+1,r]=2/h²`），或等价地做相似变换 `W^{-1/2}AW^{-1/2}` 后再用 `eigsh`；并报告本征对残差与设置扫描。
* 更稳妥：**大 d 直接使用重叠积分/渐近式**，超模法只用于 d≤25 µm 的校验。
* 实测依据：legacy 矩阵非对称（3.6–4.9%），残差 1e-2…1e-4，重复 8 次 κ(50) 差 258×；对称化后残差 4e-14、κ(d) 单调并与重叠积分相容。
* 验收：κ(d) 对 d 单调、d=50 µm 的 κ 与 1-D EIM 重叠值（1.98e-10 mm⁻¹）在 2× 内；同一调用重复 10 次平台值离散 <1%（用固定 ARPACK 起始向量或确定性求解器）。

## P1（决定物理正确性）

**P1-1 离散色散一致的 β**
* 所有模块统一：模式求解器给出"物理 β=√Λ"与"网格传播常数 β_disc=acos(…)"两个字段并标明用途；CMT/Born/耦合模型用物理 β，FDFD 传播用 β_disc；不得混用（实测二者在 h=0.15 差 5.67%）。

**P1-2 CMT 参考模型（用于交叉验证）必须换掉 d_lo 钳位**
* 对 d<d_lo 用物理外推（κ0e^{−γd}）而不是平台常数；CMT 的适用性判据 (`|A|≪1`) 必须输出；5° 时物理 κ 的 CMT 给 |A|=1.29（强耦合），此时 CMT 只能作量级参考，不能作"参考真值"。
* 实测依据：legacy CMT −30 dB @5° 中 86.5% 的 |κ| 积分来自钳位平台。

**P1-3 `crossing_born` 必须重推或删除**
* 旋转条带的 2-D 重叠积分不能因子化为 Φ(q)²/sinθ（漏 β sinθ 横向 Fourier 因子与正确的 1/sinθ 结构）；实测 5° 振幅 71.6（饱和为 T=1）、10° T=0.94，与 FDFD 差 3–10 量级。
* 若不重推，禁止在报告中把它作为"校验"。

**P1-4 小角度/强耦合区的模型层级**
* 小角度（θ≲20°）两波导芯区真实重叠（5° 时重叠长度约 200 µm），属强耦合/模式合并区：必须用全波 FDFD（或超模展开）而不是弱耦合 CMT；并要求给出该区的模式转换（基模→高阶模）功率分配。实测 10° 时总导模交叉功率 2.95e-3 中 97% 在交叉波导的高阶模（2.87e-3），仅 8.4e-5 在基模——只报基模会低估交叉损耗/串扰通道。
* 同时必须报告"基模→基模"与"总导模"两个数字，因为接收端通常只收基模。

**P1-5 近邻耦合（平行段）必须有物理模型并接入矩阵**
* 现有 `interaction_regions.csv`（61691 条）只有几何距离、无 κ/功率、从未被 board 读取；必须对每条记录赋 κ(d_eff)（用收敛的 κ 数据库/渐近式）并计算功率转移，输出到矩阵。
* 验收：近邻项与交叉项在同一能量记账框架内；平行段长度积分收敛（d→大时贡献→0）。

**P1-6 弯曲/过渡损耗**
* `bend_extra_loss_db=0` 是未建模，不是计算结果；需给出与曲率相关的损耗模型（至少给出上限），或明确声明忽略并给不确定度。

## P2（一致性与可复现性）

* **P2-1 配置漂移**：`config/simulation_config.yaml` 与实际运行参数必须由同一入口生成（run_e3 用 d_port=10/pml=5/max_unknowns=420k，配置文件是 20/4/230k；`pml_cells` 从未使用）。
* **P2-2 报告验证声明必须可执行**：删除硬编码的"平行耦合器 −20.9/−21.3 dB"（`report.py:209-213`，且重复两次）；no-cross 对照要换成**能测噪声底**的对照（例如弱扰动/已知解析散射体）；"网格/域收敛与能量守恒检查"必须真的跑并有 CSV 输出。
* **P2-3 输入校验**：`dataio.load_dataset` 对 SHA256 清单中缺失文件要给明确错误；把 `total_length_mm_expected`、`crossing_events_expected` 变成加载时断言。
* **P2-4 输出鲁棒性**：`write_csv` 的 `extrasaction="ignore"` 应改为并集字段或报错；`T_loss=max(0,…)` 不得抹平负损耗。
* **P2-5 单位与命名**：`n2` 有时指 n²、有时指 n（`_index_grid_2d` 返回 n²，`modes.index_grid` 返回 n）——这正是 F1 的来源，CTP-2.0 必须用不同变量名/类型标注消除歧义。

## 哪些 legacy 数字可以安全复用

| 类别 | 结论 | 依据 |
|---|---|---|
| **几何/长度**：1024 条线路真实弧长、分段分解、过渡 S 曲线 | ✅ **可直接复用** | 总长误差 −3.4e-7 mm（相对 −2.2e-12），逐路 <5e-10 mm；解析 G1 双圆弧与 JSON 原语一致 |
| **交叉检测**：1283 事件 / 1221 对 / 647 路 / 20 平面、位置、角度、弧长坐标 | ✅ **可直接复用** | 与官方 crossing_stats 完全一致；位置 1258/1283 匹配（其余为弧-弧交点的量化差） |
| **传播损耗**：0.05 dB/cm × 弧长（0.005 dB/mm） | ✅ **可复用**（须保留"弯曲额外损耗=0"的假设声明） | 单位换算正确；单路 0.224–1.412 dB、均值 0.765 dB 与长度一致 |
| **模式求解**：3 个导模、基模 n_eff=1.504557、EIM 一致性 0.0018% | ✅ **可复用**（需声明标量弱导近似） | 实测 n_guided=3、收敛 7e-5 |
| **超模 κ(d≤25 µm)** | ⚠️ **仅在修复非对称矩阵后可用**（当前实现不可用） | 重复性 258×；对称化后与重叠积分相容 |
| **重叠积分 κ(d≤20 µm)** | ⚠️ 小 d 可用（误差 3–26%）；大 d 不可用 | graded 网格细区 ±13.5 µm 限制 |
| **交叉 T_cross / T_through / T_loss（FDFD）** | ❌ **不可用** | 入射模错误；2–5 个量级偏差；T_through>1 |
| **交叉 CMT（−30/−41.1/−50.5 dB）** | ❌ **不可用** | d_lo 钳位占积分 86.5% |
| **交叉 Born** | ❌ **不可用** | 旋转几何代数错误；5°/10° 饱和 |
| **全板 1024×1024 矩阵与全部 headline 数字**（−65.91 dB、−58.38 dB、列和、热点、分层统计） | ❌ **不可用** | 固定 p=1e-7 的概率记账，与光学无关；角度/位置/近邻均未进入 |
| **近邻记录（61691 条）** | ⚠️ 几何部分可用；物理模型缺失 | 无 κ/功率、未接入矩阵；最小非交叉距离 50 µm 为布局节距量化值 |

## 建议的 CTP-2.0 最小可行路径（按依赖排序）

1. 修 `crossing`：正确入射模（取芯列 n²）→ 多角度 FDFD → 四臂/多模端口（Poynting 通量）→ 网格/PML/域三重收敛表 + 90° 数值底；输出 `T_cross_fund(θ)`、`T_cross_total(θ)`、`T_through(θ)`、`R(θ)`、`Rad(θ)` 及不确定度带。
2. 修 `coupling`：对称化超模或改用 1-D EIM 大域重叠积分；输出单调 κ(d) + 渐近式 + 可分辨范围；用 κ 修 CMT（去掉 d_lo 钳位）作为独立校验，但只在 |A|<0.3 时采用。
3. 重建 board：每个交点 p 取 `T_cross_total(θ)`（并给出基模口径），能量记账用"注入=扣除"同一 p；近邻段落用 κ(d) 积分功率；跑列和/二阶项校验。
4. 报告层面：删除不可执行的验证声明；把"3 模/单模激励"假设、"弯曲损耗=0"假设、数值底、网格色散写成显式不确定性表；所有 headline 数字必须能追溯到具体 CSV 行与脚本。
