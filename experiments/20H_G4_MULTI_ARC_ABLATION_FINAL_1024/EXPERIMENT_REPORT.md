## 2. 唯一变量与预算

`enable_multi_arc = True / False`（`G4_ENABLE_MULTI_ARC=1/0`），注入点
`layer2d._LayerRouter._iter_candidates`：关闭时先按 `('S', shift)` 过滤候选规格，
再对每个构建候选做几何硬门（切点连续 + 转向相反 + 圆心不同 → 丢弃）。
保持不变：1024 连接/端口、20 高度、R15、严格 D56（0.05+0.03 mm，≥5° 合法横穿豁免）、
真三维 0.05 mm、人工 U 策略、ALNS、联合让路、接受准则、目标函数、种子、Validator。

## 4. 与 21 层历史 FINAL 实验的对照

| 指标 | 21H FINAL（只读参照） | **20H FINAL（本实验）** |
|---|---:|---:|
| 共同起点 | 3967（21H G3 1322 转换，A=+2645） | **4548**（20H G3 1395 转换，A=+3153） |
| 多圆弧线路（转换前） | 197 | **213** |
| ON 均值 | 2203.0 | **2126.3** |
| OFF 均值 | 3601.0 | **4064.0** |
| 配对均值差 | −1398.0 | **−1937.7** |
| ON 相对起点 | −44.47 % | **−53.25 %** |
| OFF 相对起点 | −9.23 % | **−10.64 %** |
| ON 长度变化 vs OFF | −4.73 % | **−4.69 %** |
| 判定 | A | **A** |

20 层少一个 body 高度、共同起点更差（4548 vs 3967），但 ON 最终交叉更低（2126 vs 2203）、
OFF 更高（4064 vs 3601），**ON/OFF 差距更大**。多圆弧的收益不是 21 层模型的特例；
在 20 层更紧的几何下，OFF 语法需要更多绕行，而 ON 仍能把亚 2R 错位压进局部 footprint。

## 8. 因果性与限制

1. **A 与 B 分离**：effect A = +3153（213 条线路的 OFF 投影，一次性几何代价）；
   effect B = 从同一 4548 起点出发的搜索差（−1937.7）。两者不合并成单一“多圆弧价值”。
2. **探索性统计**：3 个种子，不做显著性检验；报告均值、样本标准差、配对差与方向一致性。
3. **单一机器/单进程**；墙钟仅记录，主实验由计数预算停止（两组均真实触发）。
4. **结论限定**在冻结 D56 候选语法（轴对齐直线 + R15 四分之一弧 + 两切点短 S）与 20H
   高度表内；不声称“多圆弧优于所有光滑曲线”。
5. **route 456 的扩展搜索**只扩大合法候选范围（高度/lead），未放松任何几何或验证约束。
6. OFF 臂最终 `multi_arc_regions=0` 由独立分类器/审计复算，不是引擎自报。
