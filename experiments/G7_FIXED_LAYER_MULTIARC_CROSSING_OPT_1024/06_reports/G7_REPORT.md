## 3. 算法：固定层 MultiArc 模拟退火

### 3.1 目标函数与接受准则

`E = N_cross`（真实同层交叉事件总数）。仅当交叉数完全相同时才比较① 最小交叉角裕量 ② 唯一交叉线路对 ③ 总路径长度；长度不会否决任何交叉数下降。接受概率 `P = min(1, exp(-ΔN/T))`，允许阶段性 +1/+2 交叉以跳出局部最优；`T0 = 1.0`、`T_end = 0.05`，停滞 300 s 再升温。

### 3.2 邻域（全部固定层）

| 邻域 | 操作 | 臂 |
|---|---|---|
| N1 | 单线路主体 MultiArc 重新生成（固定 A/B 位姿与高度） | A/B/C |
| N2 | 两条实际交叉线路同时重生成，原子 batch 评价 | B/C |
| N3 | 交叉连通分量内 3–5 条线路联合重生成 | B/C |
| N4 | 高交叉线路重点重构（top 5% 加权选择） | C |
| N5 | 整层交叉热点 6–10 条线路联合重规划 | C |

候选来自冻结的 layer2d MultiArc 语法（每个位姿 300–700 个候选）以及 G5 的精确走廊平移移动；生成后先对**不可移动的冻结邻居**做一次权威 D56/角度预筛并缓存，运行时再对少量可移动邻居做完整权威评价。

## 6. 科学分析

### 6.1 交叉下降的归因

SA 全程记录的**有效改进移动**次数：N1=493、N2=38、N3=9。单线路 N1 是数量上的主力；N2/N3 在残差热点上提供原子联合修复。

### 6.2 残余交叉的可消除性探针

对当前残余中交叉最多的 30 个线路对，逐对测试“保持固定层与过渡、只改端点线路主体 MultiArc/走廊”能否严格降低交叉数：

* 仍可由**单线路主体重规划**进一步降低：**8** 对；
* 在本次候选空间内未找到单线路改进（搜索受限或固定结构阻挡）：**22** 对。

注意：这是**搜索能力**证据，不是数学下界。剩余交叉的主要阻挡来自：① 端口位姿把部分主干钉死；② 固定高度下 R15 圆弧必须与其他线路保持 ≥45° 切线角，可用走廊被压缩；③ 人工 U 与 Native-3D 结构完全冻结；④ D56 交叉窗口使“贴着走”的候选全部非法；⑤ 部分残余对的两条线路都不可修改（direct/manual/native）。

### 6.3 实现缺陷与诚实说明（重要）

本轮在中期发现并修复了一个**搜索实现缺陷**：G7 引擎最初按“最后出现的物理层”给线路登记所属高度，而标准 5 段线路同时拥有位于接口高度（0.025 / 0.525 mm）的两段引出直线，导致相当一部分线路被错误地登记到**出口接口层**。后果是：候选评价与逐次审计打在了错误的层上，部分被接受的移动在真实主体层上未经过校验；同时交叉账本与真实几何不一致（第二轮之前的“快速下降”即为该假象）。

修复方式：线路所属高度改为**真实主体 flat 的高度**（由冻结清单 `body_index` 取 `parts[body_index].z_mm`）；并保留“每次接受后对真实主体层做权威 fslw 严格审计、非法即原子回滚、审计结果整体替换增量账本”的强制门。修复后：

* 本章 4.1–4.3 的干净消融实验（`arm_*_plane`）与 4.4 的 `final_sa`、4.5 的 `polish_fixed_plane` 均使用**平面正确**引擎；
* 早期 `arm_A_n1` / `arm_B_joint` / `arm_C_hotspot` / `phase2_*` 目录保留在 `02_sa_runs/_pilot_wrong_plane/` 仅作缺陷过程记录，其数值**不作为**固定层优化结论；
* 最终交付解只从“平面正确 + 固定结构 + A/B 双验证”全部通过的 payload 中选取。
